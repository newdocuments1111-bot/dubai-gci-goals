# Dubai Gci Goals

Name the app “Dubai AI GCI” and show it as the title.

Build a one-screen GCI calculator in AED for Dubai real estate agents. Toggle between “Start from my goal” (yearly GCI goal, default 1,000,000) and “Start from my effort” (calls per week).

Editable inputs: property price 2,000,000, commission 2%, agent split buttons 60% or 80%, 46 working weeks, and conversion rates: calls to talks 36%, talks to appraisals 34%, appraisals to listings 59%, listings to deals 31%.

Show deals, listings, appraisals, talks, calls per year, per week and per day (round up), plus the agent’s yearly take-home. Add a note: “These % are examples. Change them to your own.”

Leave space below for an “AI lead finder” section, which we’ll add later.

Clean, modern, mobile-friendly design.
